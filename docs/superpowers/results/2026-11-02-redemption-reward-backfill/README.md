## 交付行为

- 默认读取并预览；固定历史截止秒数、逐码事实、当前规则、汇总与目标数据库，0600 清单及准确 SHA256 控制执行。
- 唯一兑换码 ID 的永久账本独立于可清理日志；逐码锁定并核验，奖励、成功账本及邀请人系统日志同事务。重试、并发、进程崩溃均不会重复发放；日志失败则该码无奖励。
- 邀请人的“使用日志 → 系统/全部”显示每码一条补发日志，含 ID、受邀用户名、自己的奖励和原兑换时间，无完整兑换码。跨用户日志读取及未登录访问被拒绝，不开放邀请名单金额权限。
- 预览生成后规则、邀请关系、兑换/额度依据或目标数据库/schema 变化则拒绝，要求重新预览。MySQL 非 InnoDB、独立日志库等无法保障事务的环境拒绝执行。
