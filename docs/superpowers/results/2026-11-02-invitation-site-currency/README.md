# 邀请累计金额使用当前站点币种

时间：2026-11-02T00:58:44+09:00（Asia/Tokyo）。用户最新要求：按系统当前启用的币种，仅显示一个累计总额，删除按原币种分行展示；不新增币种功能或配置。

## 实现

复用 `general_setting.quota_display_type`、`USDExchangeRate` 及已有自定义币种符号/汇率。页面只有用户名和单一累计总金额，接口不再返回 currencies 数组。金额使用站点符号和两位小数，保持十进制字符串。

充值、订阅、兑换及镜像去重计算不变，原始订单和兑换快照不改写。已有美元、人民币、自定义单位按系统配置归一；兑换优先使用其冻结汇率恢复原始美元基准，再换算为当前展示单位。额度 TOKENS 模式的货币金额沿用现有 convertUSDToCurrency 的美元基准。缺失可信币种或系统可用换算依据的记录不猜测、不直接相加，保留不完整标记；没有可确认金额时为 null，不能伪装成实付 0。没有支付记录的已知零额显示 0.00。

测试站点当前 USD，1 USD=7.3 CNY。合成记录统一后显示 `$7.67`，附换算估算/历史不完整标记；不再显示 USD 6.3、CNY 10 两行。静默增量刷新、10 秒请求超时、后台授权和账号隔离保留。
