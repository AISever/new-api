## 文档封存后的核对方法

本文作为独立文档提交追加到维护分支；最终交付 SHA 以包含本文的分支 tip 为准，不是上表记录的文档前基线。提交并 push 后，在维护工作区执行：

```sh
git status --porcelain=v1 --untracked-files=all
git rev-list --count --branches --not --remotes
git rev-list --left-right --count HEAD...@{upstream}
git rev-parse HEAD
git ls-remote --heads origin refs/heads/codex/invitation-details-20261101
git worktree list
```

工作区应无输出，未被远端引用覆盖的本地分支提交数应为 `0`，当前分支 ahead/behind 应为 `0 0`，本地 `HEAD` 与真实远端 SHA 应相同。另在主工作区检查 `git status`，确认 `main` 仍干净并与 `origin/main` 一致。后续若继续修改，应重新核验，不能沿用本次快照。
