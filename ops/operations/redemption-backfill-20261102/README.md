# 已完成的历史返奖操作

此目录是 2026-11-02 已授权并完成的单次生产操作记录，**不是通用运行入口**。结果和备份见 [RESULTS.md](RESULTS.md)。

- `controls.py`：固定清单/收益/日志/全量保留条件与恢复门禁。
- `operation.py`：排空停写、最终备份与隔离恢复、调用已验证独立工具、重复验证、恢复原服务及观察；不会更新生产应用或镜像。
- `prepare_remote.py`：捕获现场与准备无网络恢复副本。
- `guardian.py`：只恢复服务，不补发收益；中断后先停止所属工具容器，并审计任何已提交记录。
- `verify_api_remote.py`：只读生产日志接口核验，使用既有凭据，不创建访问权限。
- `test_controls.py`：14 项离线控制测试。

默认目录保存首次未发钱的安全中止；`BACKFILL_OPERATION_SUFFIX=-retry1` 保存已完成的有效尝试。现场私有目录包含凭据，仓库仅保存脱敏摘要。
